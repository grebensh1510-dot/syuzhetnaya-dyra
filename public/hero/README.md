# Фон главного экрана

**Фотография уже стоит:** `ionych-1680.jpg` (194 КБ) на широком экране
и `ionych-900.jpg` (67 КБ) на узком. Исходный PNG весил 2,7 МБ — для
главного экрана на школьном телефоне это неприемлемо, поэтому он
пережат и удалён.

Если меняете снимок, прогоните его через тот же шаг:

```bash
node -e "const s=require('sharp');s('исходник.png').resize(1680).jpeg({quality:82,mozjpeg:true}).toFile('public/hero/ionych-1680.jpg');s('исходник.png').resize(900).jpeg({quality:80,mozjpeg:true}).toFile('public/hero/ionych-900.jpg')"
```


Положите сюда файл **`ionych.jpg`** — и он сразу встанет фоном главного
экрана. Больше ничего менять не нужно: путь уже прописан в
`src/pages/index.astro`.

```
public/hero/ionych.jpg
```

Пока файла нет, компонент рисует сепийную подложку: композиция, наезд
камеры, туман и зерно видны, но фотографии на них нет.

## Каким должен быть снимок

- Горизонтальный, не меньше 2400 px по ширине — кадр наезжает до 106 %,
  и на ретине мягкость будет заметна.
- Светлый и приглушённый. Текст поверх — тёмно-винный, подложка светлая;
  тёмная фотография потребует переверстать `.cine__scrim`.
- Смысловой центр лучше держать правее и ниже середины: слева стоит
  эпиграф, по центру — заголовок «Ионыч».
- JPEG с качеством 78–85. Снимок на весь экран — самый тяжёлый файл сайта.

Кадрирование по вертикали настраивается пропсом без правки стилей:

```astro
<CinematicPhoto src="/hero/ionych.jpg" position="center 38%">
```

## Если фотографий будет несколько

Компонент `src/components/CinematicPhoto.astro` не привязан к главной
странице: его можно ставить на любой экран, передав свой `src`.
